# Recetas

Pasos concretos para las tareas más comunes. Cada receta dice qué archivos
tocar, trae un ejemplo que pasa `composer check` y termina con los errores
que conviene evitar. La API completa está en `../reference.md`.

| Receta                                    | Cuándo usarla                                         |
| ----------------------------------------- | ----------------------------------------------------- |
| [crear-crud.md](crear-crud.md)            | Una pantalla de alta, lista, edición y borrado        |
| [proteger-rutas.md](proteger-rutas.md)    | Solo usuarios con sesión, o cada quien ve lo suyo     |
| [endpoint-json.md](endpoint-json.md)      | Datos en JSON para JS propio o para otra aplicación   |
| [crear-componente.md](crear-componente.md) | Una pieza de interfaz reutilizable, con o sin JS     |
| [migracion.md](migracion.md)              | Crear o cambiar tablas                                |
| [subir-archivos.md](subir-archivos.md)    | Imágenes, PDFs y otros archivos de usuarios           |
| [enviar-correo.md](enviar-correo.md)      | Avisos por correo                                     |
